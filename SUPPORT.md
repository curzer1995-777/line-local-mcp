# Support

LINE Local MCP is a volunteer-maintained beta project. Support is best-effort and no response time is guaranteed.

## Where to ask

- Installation, compatibility, and bug reports: use the appropriate [GitHub issue template](https://github.com/curzer1995-777/line-local-mcp/issues/new/choose).
- Feature ideas: use the feature-request template.
- Security vulnerabilities or reports containing sensitive details: follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting.

Before asking for help, run:

```bash
.venv/bin/line-local-mcp --doctor
```

Share only the non-sensitive readiness result plus macOS, LINE Desktop, Python, and project versions. Do not share real chats, databases, WAL/SHM files, Keychain values, memory dumps, usernames, private paths, tokens, or account identifiers.

The project supports the latest release and `main` on a best-effort basis. Compatibility with undocumented LINE storage can break after a LINE update.
